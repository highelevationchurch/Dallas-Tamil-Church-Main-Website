Yakkobennum

யாக்கோபென்னும் சிறு பூச்சியே – நீ
ஒன்றுக்கும் கலங்கி விடாதே
இஸ்ரவேலின் சிறு கூட்டமே
நீ எதற்கும் பயந்து விடாதே

உன்னை உண்டாக்கினவர்
உன்னை சிருஷ்டித்தவர்
உன் முன்னே நடந்து செல்கிறார்
தீங்கு உன்னை ஒன்றும் செய்யாதே

1. அழைத்தவர் கைவிடுவாரோ
இல்லை இல்லை இல்லை
தெரிந்தவர் விட்டிடுவாரோ
இல்லை இல்லை இல்லை - (2)
பெயர் சொல்லி அழைத்த தேவன் - (2)
உன்னை மகிமை படுத்திடுவார் - (2)
- உன்னை உண்டாக்கினவர்
- யாக்கோபென்னும்

2. பலவீனன் ஆவதில்லை
இல்லை இல்லை இல்லை
சுகவீனம் தொடர்வதில்லை
இல்லை இல்லை இல்லை - (2)
சாத்தான் உன்னை ஜெயிப்பதில்லை - (2)
சாபம் உன்னை அணுகுவதில்லை - (2)
- உன்னை உண்டாக்கினவர்
- யாக்கோபென்னும்

3. வியாதிகள் வருவதில்லை
இல்லை இல்லை இல்லை
வாதைகள் தொடர்வதில்லை
இல்லை இல்லை இல்லை - (2)
ஆண்டுகள் முடிவதில்லை - (2)
அவர் கிருபையும் விலகுவதில்லை - (2)
- உன்னை உண்டாக்கினவர்
- யாக்கோபென்னும்

Yaakkoabennum siru poochiyae – Nee
Ondrukkum kalangi vidaadhae
Isravaelin siru koottamae
Nee edharkum payandhu vidaadhae

Unnai undaakkinavar
Unnai sirushtithavar
Un munnae nadandhu selgiraar
Theengu unnai ondrum seiyaadhae

1. Azhaithavar kaividuvaaroa
Illai illai illai
Therindhavar vittiduvaaroa
Illai illai illai - (2)
Peyar solli azhaitha dhaevan - (2)
Unnai magimai paduthiduvaar - (2)
- Unnai undaakkinavar
- Yaakkoabennum

2. Palaveenan aavadhillai
Illai illai illai
Sugaveenam thodarvadhillai
Illai illai illai - (2)
Saathaan unnai jeyippadhillai - (2)
Saabam unnai anuguvadhillai - (2)
- Unnai undaakkinavar
- Yaakkoabennum

3. Viyaadhigal varuvadhillai
Illai illai illai
Vaadhaigal thodarvadhillai
Illai illai illai - (2)
Aandugal mudivadhillai - (2)
Avar kirubaiyum vilakuvadhillai - (2)
- Unnai undaakkinavar
- Yaakkoabennum
