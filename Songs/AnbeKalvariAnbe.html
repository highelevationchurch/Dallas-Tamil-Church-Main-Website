Anbe Kalvari Anbe

அன்பே கல்வாரி அன்பே
உம்மைப் பார்க்கையிலே
என் உள்ளம் உடையுதப்பா

1. தாகம் தாகம் என்றீர்
எனக்காய் ஏங்கி நின்றீர் -- (2)
பாவங்கள் சுமந்தீர் - எங்கள்
பரிகார பலியானீர் - எங்கள் -- (2) -- அன்பே கல்வாரி அன்பே

2. காயங்கள் பார்க்கின்றேன்
கண்ணீர் வடிக்கின்றேன் -- (2)
தூய திரு இரத்தமே
துடிக்கும் தாயுள்ளமே - எங்கள் -- (2) -- அன்பே கல்வாரி அன்பே

3. அணைக்கும் கரங்களிலே
ஆணிகளா சுவாமி? -- (2)
நினைத்து பார்க்கையிலே
நெஞ்சம் உருகுதையா - எங்கள் -- (2) -- அன்பே கல்வாரி அன்பே

4. நெஞ்சிலே ஓர் ஊற்று
நதியாய் பாயுதையா -- (2)
மனிதர்கள் மூழ்கணுமே
மறுரூபம் ஆகணுமே - எங்கள் -- (2) -- அன்பே கல்வாரி அன்பே
