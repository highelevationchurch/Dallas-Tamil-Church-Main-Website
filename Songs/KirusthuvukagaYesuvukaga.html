Kirusthuvukaga Yesuvukaga

கிறிஸ்துவுக்காக இயேசுவுக்காக
ஜீவன் தந்த தேவனுக்காக (2)
ஏதாவது ஒன்றை செய்ய என் மனம் துடிக்குது (2)
- கிறிஸ்துவுக்காக இயேசுவுக்காக

அவர் கரத்தின் கிரியைகள் நினைக்கும் போது
ஏதாவது ஒன்றை செய்ய என் மனம் துடிக்குது
அவர் கரத்தின் செய்கைகள் நினைக்கும் போது
ஏதாவது ஒன்றை செய்ய என் மனம் துடிக்குது
- கிறிஸ்துவுக்காக இயேசுவுக்காக

ஒரு தகப்பனைப் போலே சுமந்ததை நினைத்தால்
ஏதாவது ஒன்றை செய்ய என் மனம் துடிக்குது
ஒரு தாயைப் போலே அணைத்ததை நினைத்தால்
ஏதாவது ஒன்றை செய்ய என் மனம் துடிக்குது
- கிறிஸ்துவுக்காக இயேசுவுக்காக

என் ஜீவன் எனக்குள் இருக்கும் வரைக்கும்
ஏதாவது ஒன்றை செய்ய என் மனம் துடிக்குது
என் பலவீனத்தில் உயர்த்தி மகிழ்ந்ததால்
ஏதாவது ஒன்றை செய்ய என் மனம் துடிக்குது
- கிறிஸ்துவுக்காக இயேசுவுக்காக
